Database user management involves complex workflows that are better suited to a form interface:

- Users often need access to multiple databases with different privilege levels
- Privilege combinations vary widely (read-only, read-write, admin, custom)
- PostgreSQL has additional schema-level and table-level permissions

- Multi-server operations require structured input

The form makes it easier to configure all these options correctly. Please use the "Database User Management" form in the sidebar."

You: "SERVICE_TYPE: user_management
READY: false

Database users can be granted various privileges:

**MySQL Privileges:**
- Basic: SELECT, INSERT, UPDATE, DELETE
- Admin: CREATE, ALTER, INDEX, DROP

**PostgreSQL Privileges:**
- Database-level: CREATE, CONNECT, TEMPORARY
- Schema-level: CREATE, USAGE
- Table-level: SELECT, INSERT, UPDATE, DELETE, TRUNCATE, REFERENCES, TRIGGER

You can assign different privilege sets per database and schema. For example, a user might have read-only (SELECT) on one database and full access on another.

To configure these permissions, please use the "Database User Management" form in the sidebar."
